STUDY QUEST

HOW TO RUN
1. Extract the ZIP.
2. Open the study-quest folder.
3. Double-click index.html.
4. It runs entirely in your browser.

Your tasks, reward, exam date, sessions and brain dump are saved in browser localStorage.

FILES
- index.html = page structure
- style.css = appearance
- script.js = functionality

IMPORTANT
Do not clear browser site data/localStorage if you want to keep your saved study history.

FEATURES
- Daily study task list
- Task durations/types
- Completion progress
- Daily reward that unlocks when all tasks are done
- Exam countdown
- 5/10/15/25/45 minute focus timer
- 5-minute starter
- "Pick for me"
- "I don't want to study" micro-start sequence
- Distraction parking lot
- Focus Mode
- XP
- Study session history
- Browser persistence via localStorage
- Responsive mobile layout
